# Skills

| File | For |
|---|---|
| `DAILY_REPORT_GUIDANCE.md` | Writing a client's daily brief |
| `WEEKLY_REPORT_GUIDANCE.md` | Writing a client's weekly competitive report |
| `FIND_LEADS.md` | Turning public social posts into named people the client can contact today |
| `FIND_CUSTOMERS_OF_COMPETITORS.md` | Working out who is paying a competitor, and which of them can be taken |
| `SCRAPING_TOOLBOX.md` | Reference for the two above: actors, inputs, prices, gotchas |
| `INTEGRATIONS.md` | What we have connected, what to connect next, outside skills worth borrowing |
